# Learning FLET

This repository contains various mini and major projects created to learn and demonstrate the capabilities of the Flet framework. Each project is self-contained in its own directory.

## How to Run

1.  Clone the repository:
    ```bash
    git clone https://github.com/ayushgoyal04/Learning-FLET.git
    ```
2.  Navigate to the desired project folder (e.g., `cd miniProject_1`).
3.  Install the main dependency:
    ```bash
    pip install flet
    ```
4.  Run the project:
    ```bash
    python main.py
    ```

## Mini Projects

A collection of small applications, each focusing on a specific Flet feature or concept.

- **miniProject_1: Counter App**
  - A simple counter with increment, decrement, and reset buttons.
- **miniProject_2: Theme Switcher**
  - An app to toggle between light and dark themes.
- **miniProject_3: Digital Clock**
  - A live digital clock that updates every second.
- **miniProject_4: Dice & Coin Toss**
  - A simulator for rolling a die and tossing a coin.
- **miniProject_5: Guess the Number**
  - A classic number guessing game with feedback and attempt tracking.
- **miniProject_6: Character Counter**
  - A real-time character counter for a text input field.
- **miniProject_8: Empty Project**
  - A placeholder project.
- **minProject_9: Image Viewer**
  - An app to select and display a local image file.
- **miniProject_10: Drawing Canvas**
  - A simple pixel drawing canvas.
- **miniProject_11: Password Strength Checker**
  - An app that provides real-time feedback on password strength.
- **miniProject_12: Multiplication Table Generator**
  - Generates a multiplication table for a given number.
- **miniProject_13: Login Page**
  - A basic, static login page with hardcoded credentials.

## Major Projects

More complex applications that integrate multiple features.

- **majorProject_1: Text Editor**
  - A simple text editor that can open, edit, and save `.txt` files, with "Save As" functionality.
- **majorProject_2: Notes App with Database**
  - A persistent notes application that uses a SQLite database to store, view, and delete notes.
- **majorProject_3: Flet Application Template**
  - A template for creating a distributable Flet application, complete with build instructions for various platforms.

Enjoy exploring the projects built with Flet!
