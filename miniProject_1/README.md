# Mini Project 1: Counter App

This Flet application is a simple counter.

## Features

- **Increment:** Click the '+' button to increase the counter by 1.
- **Decrement:** Click the '-' button to decrease the counter by 1.
- **Reset:** Click the 'Reset' button to set the counter back to 0.

## How it Works

The application displays a number, which starts at 0. Below the number, there are three buttons. The '+' and '-' buttons call respective functions (`increase` and `decrease`) to modify the counter's value and update the display. The 'Reset' button uses a lambda function to directly set the counter's value back to "0" and refreshes the text control.
